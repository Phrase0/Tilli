根畫面

場次 EventsPage

場次列表

EventsView

打開 App 第一個看到的畫面，列出所有場次。

  • 可切換「列表」與「日曆」兩種顯示；列表分成今天、即將到來、已結束，可搜尋。
  • 新增、編輯、複製場次；單筆或批次刪除（目前是真的刪掉，見 FEATURE_PLAN_V2.md §2.2）。
  • 點場次進入場次工作區，預設分頁依場次狀態決定：沒有商品或未開始 → 管理商品、進行中 → 收銀、已結束 → 報表。
  • 右上角進「我的」。

收銀 POSPage

收銀

POSView

場次工作區的「開始收銀」分頁。

  • 依類別分區列出可販售的商品與套餐，可切換列表／格狀；上方 chip 列跳區。
  • 加減數量進購物車；組合符合條件時自動套用。
  • 按「結帳」打開結帳視窗；付款成功、視窗關閉後顯示「付款完成」方塊。
  • 購物車裡的商品被下架或庫存不足時，提示並移除。

流程

  • 結帳（現金）
  • 作廢交易
  • 新增／編輯商品
  • 進入場次工作區
  • 刪除場次（現況：硬刪除）
  • App 啟動與登入狀態（現況，第 1 批移除）

結帳（現金）

收銀頁從購物車到寫入交易。電子支付的流程相同，只是付款頁換成 EPaymentView／EPaymentViewModel。 交易、銷售扣庫存的異動、商品庫存在同一次存檔完成，失敗時全部不留。

sequenceDiagram
    actor U as 攤商
    participant POSView
    participant POSViewModel
    participant CheckoutSummaryView
    participant CashPaymentView
    participant CashPaymentViewModel
    participant CheckoutRecorder
    participant EventRepository
    participant DB as CoreData

    U->>POSView: 點商品／套餐加入購物車
    POSView->>POSViewModel: 更新購物車（CartPricing 算價、ComboApplier 套組合）
    U->>POSView: 按「結帳」
    POSView->>CheckoutSummaryView: 打開結帳視窗（CheckoutFlowView）
    U->>CheckoutSummaryView: 確認內容、（可選）改交易日期、選現金
    CheckoutSummaryView->>CashPaymentView: 帶著定價快照進付款頁
    U->>CashPaymentView: 輸入收款金額、按「完成」
    CashPaymentView->>CashPaymentViewModel: performCheckout
    CashPaymentViewModel->>CheckoutRecorder: stockUpdates（算出結帳後各商品庫存）
    CashPaymentViewModel->>CheckoutRecorder: makeRecord（RevenueAllocator 攤提折扣）
    CashPaymentViewModel->>EventRepository: recordCheckout(交易, 庫存)
    EventRepository->>DB: 交易＋銷售異動＋商品庫存，同一次存檔
    alt 存檔失敗
        EventRepository-->>CashPaymentViewModel: false
        CashPaymentViewModel-->>U: 「結帳失敗」，留在付款頁
    else 成功
        EventRepository-->>CashPaymentViewModel: true
        CashPaymentView->>POSView: 回報金額並關閉結帳視窗
        POSView->>POSViewModel: loadProducts（EventDataSource.reload）
        POSView-->>U: 視窗關閉後顯示「付款完成」方塊
    end

作廢交易

交易明細頁作廢一筆交易。交易本身不改不刪，另外新增一筆作廢紀錄（CDTransactionVoidEntity）； 選「回流」時再新增「作廢回流」庫存異動並加回庫存。三者同一次存檔。

sequenceDiagram
    actor U as 攤商
    participant TransactionDetailView
    participant VoidTransactionView
    participant VoidTransactionViewModel
    participant VoidRecorder
    participant EventRepository
    participant DB as CoreData

    U->>TransactionDetailView: 按「作廢交易」
    TransactionDetailView->>VoidTransactionView: 打開作廢視窗
    U->>VoidTransactionView: 選原因、選回流與否、按「作廢」並確認
    VoidTransactionView->>VoidTransactionViewModel: performVoid
    VoidTransactionViewModel->>VoidRecorder: makeRecord（已作廢、沒選原因或回流 → 拒絕）
    VoidTransactionViewModel->>VoidRecorder: stockUpdates（回流後各商品庫存）
    VoidTransactionViewModel->>EventRepository: recordVoid(作廢紀錄, 庫存)
    EventRepository->>DB: 確認沒有重複作廢；作廢紀錄＋回流異動＋庫存，同一次存檔
    alt 存檔失敗
        EventRepository-->>VoidTransactionViewModel: false
        VoidTransactionViewModel-->>U: 「作廢失敗」，留在視窗
    else 成功（或已被作廢而拒絕）
        VoidTransactionViewModel->>VoidTransactionViewModel: EventDataSource.reload
        VoidTransactionView->>TransactionDetailView: 關閉視窗
        TransactionDetailView->>TransactionDetailView: refreshVoidState，顯示作廢卡片
    end

新增／編輯商品

商品與庫存異動（新增時的初始庫存、編輯時的庫存調整）在同一次存檔完成。

sequenceDiagram
    actor U as 攤商
    participant InventoryView
    participant EventWorkspaceView
    participant AddNewProductView
    participant AddNewProductViewModel
    participant ProductRepository
    participant DB as CoreData
    participant InventoryViewModel

    U->>InventoryView: 新增商品，或點商品編輯
    InventoryView->>EventWorkspaceView: 設定要開的表單
    EventWorkspaceView->>AddNewProductView: 推入商品表單（帶存檔成功的回呼）
    U->>AddNewProductView: 填圖片、名稱、類別、價格、庫存，按儲存
    AddNewProductView->>AddNewProductViewModel: save
    AddNewProductViewModel->>AddNewProductViewModel: 驗證欄位、同類別同名檢查
    alt 新增
        AddNewProductViewModel->>ProductRepository: addProduct(商品, initialChange: 初始庫存異動)
    else 編輯
        AddNewProductViewModel->>ProductRepository: updateProduct(商品, stockChange: 庫存調整異動)
    end
    ProductRepository->>DB: 商品＋庫存異動，同一次存檔
    alt 存檔失敗
        ProductRepository-->>AddNewProductViewModel: 失敗
        AddNewProductViewModel-->>U: 「儲存失敗」，留在表單
    else 成功
        AddNewProductView->>EventWorkspaceView: 存檔成功回呼，返回管理商品頁
        EventWorkspaceView->>InventoryViewModel: loadData（EventDataSource.reload）
    end

點場次後建立一份 EventDataSource，三個分頁共用。之後各分頁出現時（onAppear）呼叫 reload 取最新快照， 頁面之間不互相通知。

    U->>EventsView: 點場次

刪除場次（現況：硬刪除）

目前是真的刪掉，不檢查有沒有交易。類別、商品、庫存異動由 CoreData Cascade 一起刪除； 交易保留但不再屬於任何場次。改成軟刪除的規劃見 FEATURE_PLAN_V2.md §2.2。

sequenceDiagram
